# YT Content Tracker

Este repositorio contiene dos ejemplos minimos e independientes para comparar
Electron y Tauri.

## Electron

Requiere Node.js y npm.

```powershell
cd electron
npm install
npm start
```

## Tauri

Requiere Rust, las dependencias del sistema indicadas en la guia de Tauri y la
CLI de Tauri instalada.

```powershell
cd tauri
cargo install tauri-cli
cargo tauri dev
```

Los ejemplos son puntos de partida separados; no se ejecutan juntos.
